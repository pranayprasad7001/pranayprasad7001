## 🔥 What I'm Building

My current focus is moving beyond simple LLM applications toward **reliable AI systems**.

A recent example is my **Enhanced Multi-Document Search RAG**, which combines:

```text
                    User Query
                        │
                        ▼
                Security Guardrails
                        │
                        ▼
                 Query Analysis
                        │
             ┌──────────┴──────────┐
             ▼                     ▼
       Hybrid Retrieval       External Search
             │                  MCP Tools
             ▼
      Document Grading
             │
       ┌─────┴─────┐
       ▼           ▼
    Relevant     Weak
       │           │
       ▼           ▼
   Generation   Query Rewrite
       │           │
       ▼           └──────► Retrieval
Hallucination Check
       │
       ▼
Answer Relevance
       │
       ▼
Output Guardrails
       │
       ▼
     Answer
```

The system includes:

- LangGraph adaptive orchestration
- Hybrid dense + BM25 retrieval
- AstraDB
- Cohere reranking
- Query rewriting
- Retrieval grading
- Hallucination detection
- Answer relevance grading
- MCP tools
- LiteLLM gateway
- Model routing and fallback
- Redis semantic caching
- PII middleware
- Input/output guardrails
- Tool-call/result filtering
- Per-query latency and cost tracking
- LangGraph Studio
- Streamlit
